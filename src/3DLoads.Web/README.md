# 3DLoads Web Demo

Requires Node.js/npm and the .NET 8 SDK. From this directory, run:

```powershell
npm install
npm start
```

The start command runs Angular at `http://localhost:4202` and the stateless C# solver at port `5195`; Angular proxies solver requests locally. Use Ctrl+C to stop both processes.

The draft exists only in browser memory. Refreshing resets it. No database, login, or account setup is needed.

npm run build
npm test -- --watch=false
